# Map asset slots

Replace the hotspot slot below with your approved PNG marker. No icon artwork is generated by the project.

| File | Used in | Recommended format |
|---|---|---|
| `hotspot-icon.png` | Firehawk hotspot marker | Transparent PNG, 128 × 128 px; circular artwork with the point center aligned |

If the file is not present, the map temporarily shows the text fallback `!`; adding the PNG with the same filename activates the supplied asset automatically.
