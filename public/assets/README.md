# ATLAS asset locations

Use these folders when adding owner-provided assets:

| Folder | Put here | Current status |
|---|---|---|
| `images/` | ATLAS logo, ATLAS News photos, and patrol-unit popup photos | Active; replace the PNG slot guides using the same filenames |
| `icons/` | Search and dropdown arrow PNG slots | Replace `search-icon.png` and `arrow-icon.png` with your own assets |
| `map/` | Optional approved map-marker PNGs | Not required; current map markers remain CSS-based |
| `data/` | Runtime SHP data source | Replace `DataSHP.zip` while keeping its filename and internal layer names |

The PNG files inside `images/` are neutral placement guides. Replace them with the final files, do not rename them, and keep the recommended dimensions listed in `images/README.md`.
