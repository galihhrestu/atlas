# Interface icon asset slots

Replace the slot PNGs below with your own assets using the same filenames. The source already references these paths; no code change is required after replacement.

| File | Used in | Recommended format |
|---|---|---|
| `search-icon.png` | Search button in the top navigation | Transparent PNG, 64 × 64 px |
| `arrow-icon.png` | Reserved directional arrow asset for future cards or links | Transparent PNG, 64 × 64 px |

The navigation and Map Layers dropdowns currently use the small CSS chevron from the previous version, so replacing this reserved PNG does not change dropdown behavior.
